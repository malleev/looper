# Orange Pi Guitar Looper

Аппаратный гитарный лупер на базе **Orange Pi PC** (Allwinner H3, 1 ГБ RAM, Linux 6.6 LTS).

## Возможности:
- **Низкая задержка:** ALSA direct I/O с буфером 128 сэмплов (~2.6 мс при 48 кГц).
- **Плавное зацикливание:** Anti-Click Crossfading (5 мс) на шве петли.
- **Неограниченные овердабы** с одноуровневым Undo / Redo.
- **DSP спецэффекты:**
  - `Reverse`: воспроизведение петли задом наперед.
  - `Fade-Out`: плавное затухание петли при остановке (по умолчанию 3 сек).
- **Поддерживаемые аудиоинтерфейсы:**
  - USB Audio (Arturia MiniFuse 1) на этапе разработки и тестов.
  - I2S (PCM1808 ADC + PCM5102 DAC) в финальной педали.

## Сборка и запуск на Orange Pi:

```bash
cd ~/looper
make
./looper hw:CARD=M1,DEV=0
```

## Управление с клавиатуры:
- `[SPACE]` — Основная кнопка (Rec -> Play -> Overdub -> Play)
- `[S]` — Остановка (Stop)
- `[C]` — Очистка памяти (Clear)
- `[U]` — Отмена / возврат последнего овердаба (Undo / Redo)
- `[R]` — Включение / выключение Reverse
- `[F]` — Плавное затухание (Fade-Out)
- `[M]` — Переключение режима сквозного мониторинга звука (Dry Monitor)
- `[+] / [-]` — Громкость петли
- `[Q]` — Выход
