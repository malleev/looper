# Orange Pi Guitar Looper (Full C++ Native MVP)

Автономный гитарный лупер на базе **Orange Pi PC** (Allwinner H3, 1 ГБ RAM, Linux 6.6 LTS) с прямой работой через ALSA и аппаратным ножным/клавиатурным управлением.

## Особенности архитектуры:
- **Один монолитный бинарник:** Никаких тяжелых аудиосерверов (JACK) или сторонних демонов. Занимает ~5 МБ ОЗУ и стартует за 0.05 секунды.
- **Strict Real-Time Safety:** Аудиопоток `process()` полностью свободен от блокировок (`mutex`), динамических аллокаций (`malloc`/`new`) и дисковых операций. Управление реализовано через wait-free SPSC кольцевые очереди (`CommandQueue`, `BufferReturnQueue`, `SaveQueue`).
- **Фоновый дисковый воркер (WavWorker):** Сохранение снимков аудио и загрузка WAV-файлов выполняются в отдельном низкоприоритетном потоке без дропов в аудио. Строгая валидация частоты дискретизации 48 кГц.
- **Режимы мониторинга и Latency Model:**
  - `DIRECT_ANALOG` (по умолчанию): музыкант слушает аналоговый прямой тракт звуковой карты с нулевой задержкой. Программный Dry отключен (`0.0`), овердаб смещается назад на $K = 384$ сэмпла (~8.0 мс) в транспортном домене с идеальным согласованием при реверсе.
  - `SOFTWARE`: программный мониторинг через ALSA (`dry_gain = 1.0`). Музыкант слышит звук с задержкой тракта и естественно играет в темпе, компенсация овердаба отключена ($K = 0$).
  - Переключение на лету клавишей `[M]`.
- **Pre-Roll буфер (256 сэмплов / ~5.3 мс):** при нажатии записи захватывает атаку первой ноты, предотвращая срез первого удара по струне.
- **Недеструктивный Undo/Redo с 32-bit Float Headroom:** отказ от дублирования буфера базы (экономия более 115 МБ памяти) и суммирование без промежуточного клиппирования; лимитер работает только на выходе ЦАП.
- **Multi-pass Overdub Auditioning:** слышимость уже наложенных слоев на 2-м и последующих кругах во время записи овердаба.
- **Anti-Click Crossfade:** 5 мс микро-сглаживание на стыке зацикливания для бесшовного лупа без щелчков.
- **Двойной ввод (evdev + stdin):** Работает как из окна SSH, так и с физической USB-клавиатуры / педали, воткнутой прямо в Orange Pi.

## Сборка и запуск:

```bash
cd ~/looper
make clean && make -j4
./looper
```

Для запуска тестов:
```bash
g++ -std=c++17 -O3 -Wall -Wextra -pthread -Iinclude test/test_suite.cpp src/looper_engine.cpp src/wav_file.cpp src/wav_worker.cpp -lpthread -o test_looper
./test_looper
```

## Управление:

| Клавиша | Действие |
|---|---|
| **`[ПРОБЕЛ]`** | Record -> Play -> Overdub -> Play |
| **`[S]`** | Стоп (Stop) |
| **`[C]`** | Очистка петли (Clear) |
| **`[U]`** | Отмена / возврат последнего овердаба (Undo / Redo) |
| **`[R]`** | Реверс петли (Reverse) |
| **`[F]`** | Плавное затухание петли до остановки (Fade-out 3 сек) |
| **`[M]`** | Переключение мониторинга (`DIRECT_ANALOG` vs `SOFTWARE_DRY`) |
| **`[W]`** | Сохранить петлю в WAV файл в папку `recordings/` |
| **`[L]`** | Загрузить последний сохраненный WAV файл в память |
| **`[>]` / `[<]`** | Увеличить / уменьшить компенсацию задержки (+/- 32 сэмпла) |
| **`[+]` / `[-]`** | Громкость воспроизведения петли |
| **`[Q]`** | Выход |
